# System Sounds Keeper

## 目标

Windows 当前用户的全部活动播放设备：程序启动、设备接入/重新启用、默认播放设备切换，以及系统声音会话新建时，应用配置中的“系统声音”音量。全局默认 50%，可按音频端点 ID 覆盖。不记录用户临时手动调整，不改变设备总音量、其他应用音量、静音或默认设备。

## 实现范围

- 独立 .NET Framework 程序，无第三方依赖；PowerShell 构建及管理入口。
- IMMNotificationClient 接收设备事件；每秒检查活动端点及系统声音会话，覆盖会话延迟出现和事件丢失。
- IsSystemSoundsSession 识别系统声音，不依赖本地化显示名或进程 ID。
- 每个会话只在相关事件/配置变化后应用一次；成功后不持续强制覆盖用户音量。
- JSON 配置热重载；无效配置启动时报错，运行时保留最后一次有效配置并记录错误。
- 新端点采用全局默认值。设备 ID 因重新配对或驱动更新而变化后，需重新配置覆盖项。
- 每次后台程序实际启动后扫描全部已登记播放端点（包含离线端点），按 ID 增量追加到配置；新项使用全局默认音量。保留已有设备顺序、音量、备注、离线条目和未知字段。没有新增时不写文件；新增前备份并原子替换。无效配置不自动重建。
- 提供手动 `SyncDevices` 入口，后台运行时可随时补充设备配置；运行中首次接入的新设备仍先使用全局默认值。
- 设备清单、有限大小的本地日志、单实例、可停止；提供可选的当前用户登录自启动安装/卸载命令。

## 验证

编译和策略场景测试；本机只读列出设备；对系统声音应用 50% 后读取核实，比较设备总音量及其他会话音量。后台进程启动/状态/停止验证。真实蓝牙、USB、3.5mm 拔插和唤醒由用户随后验证，不在验证时主动切换输出或播放声音。

增量合并验证：已有自定义音量/备注/扩展字段保留、离线设备保留、新设备按默认值追加、重复扫描幂等、无效配置保持原样、写入前备份完整原文。重启后台程序验证真实设备扫描与配置合并。
